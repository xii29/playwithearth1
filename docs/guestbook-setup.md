# 카드 방명록

첫 화면은 검정 배경과 흰색 빈 카드 5장으로 시작합니다. 스크롤·하단 화살표·방향키로 원형 카드 목록을 회전할 수 있습니다. 선택한 카드에 직접 타이핑하거나 펜 도구로 마우스·터치 손글씨를 쓸 수 있습니다.

카드 색상 6종, 잉크 색상, 펜 굵기, 지우개, 획 되돌리기, 그림 지우기, 이동 가능한 스티커를 제공합니다. 그림 지우기는 글과 스티커에 영향을 주지 않습니다. 각 카드의 글·그림·색상·스티커는 독립적입니다.

우측 상단 **+ 빈 카드**를 누르면 실제 카드가 하나씩 추가됩니다. 전체 수에 맞춰 회전 각도와 반지름을 다시 계산하며, 모든 카드를 같은 회전 목록에 표시합니다. 일부 카드만 바꿔 보여주는 방식이나 페이지 구분은 없습니다. 원형 배치의 뒤쪽 카드는 앞 카드에 가려질 수 있으며 회전하면 확인할 수 있습니다.

기록은 화면 메모리에만 있고 새로고침하거나 방명록을 나가면 초기화됩니다. 서버·브라우저 저장소·카메라를 사용하지 않습니다. 기존 데이터와 사진 예제 코드는 삭제하지 않지만 현재 방명록에서는 불러오지 않습니다.

검증: `npm run build`, `node scripts/check-guestbook.mjs`, `node scripts/check-pages.mjs`. 브라우저 검증은 입력·펜·되돌리기·색상·스티커·스크롤·카드 추가·모바일 배치·새로고침 초기화를 확인합니다.
